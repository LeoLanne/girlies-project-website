# 🌸 Girlies Project - Creative & Stylish Landing Page

A responsive, elegant landing page built for a creative business and services platform tailored for women. This project showcases clean UI design, semantic HTML5 structure, and modern styling.

## ✨ Key Features
- **Semantic HTML5:** Well-structured code using modern semantic elements (`<header>`, `<main>`, `<section>`, `<footer>`).
- **Custom Typography:** Integrated with Google Fonts (*Poppins* & *Playfair Display*).
- **Iconography:** Enhanced user experience using Font Awesome 6 icons.
- **Service Showcase Grid:** Displaying creative services, social media management, and online workshops with clean pricing cards.
- **Interactive Contact Form:** Clean design with integrated social media & email links.

## 🛠️ Tech Stack
- **HTML5**
- **CSS3** (Flexbox & Responsive Layout)
- **Google Fonts & Font Awesome 6**
